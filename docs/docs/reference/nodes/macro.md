# Macros

## Macro Start

`macro.start`

Where the macro starts running when it is chained

Goes on with: **Next**

## Macro End

`macro.end`

Continues with what is chained to this exit of the macro

## Macro Input

`macro.input`

A value passed into the macro

| Out | Type | What it is |
|---|---|---|
| Value | any type | What is connected to this input where the macro is used |

## Macro Output

`macro.output`

A value the macro provides

| In | Type | What it is |
|---|---|---|
| Value | any type | What the macro gives out under this output's name |

| Out | Type | What it is |
|---|---|---|
| Value | any type | What the macro gives out under this output's name |
