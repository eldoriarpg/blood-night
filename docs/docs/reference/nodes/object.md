# Objects

## Mutate

`object.mutate`

Reads the properties of whatever is wired in, and changes those given a value

| In | Type | What it is |
|---|---|---|
| Target (optional) | Object | The object to read or change |

| Out | Type | What it is |
|---|---|---|
| Target | Object | The object, unchanged |
