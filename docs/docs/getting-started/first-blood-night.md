# Your first blood night

You don't have to wait for a lucky night. You can start one yourself. Your world needs blood nights turned on
first. The [setup](install.md#set-it-up) does that.

1. Join your server as an operator.
2. Run `/bloodnight night force`.
3. Run `/time set night`.

The blood night begins. You see a red boss bar, the screen goes dark for a moment and you hear thunder.

Now look around. Some monsters that spawn are special mobs. They have a name above their head, like
"Speed Zombie" or "Toxic Creeper".

## Spawn a special mob yourself

Want to see one right now? Run:

```
/bloodnight spawn speed_zombie
```

Type `/bloodnight spawn ` and press Tab to see all mob names.

## When does it end?

A blood night ends when the sun rises. Special mobs disappear then. You can also end it early with
`/bloodnight night cancel`.

## What happens next?

By default, about 6 of 10 nights become blood nights. Check the next one with `/bloodnight night`.

To change that, read [Choosing blood nights](../nights/choosing-nights.md).
